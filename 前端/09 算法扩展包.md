# 09 算法扩展包

前端算法面不考写完整题，考的是：**知道用什么结构、说得出复杂度、能把边界说清楚**。

## 复杂度

时间复杂度看趋势，忽略常数和低阶项。常见量级：

```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)
```

空间复杂度在前端通常不是硬约束，但要注意递归栈深度和额外数组的开销。

## 数组操作的真实代价

| 操作 | 复杂度 | 原因 |
|---|---|---|
| `push` / `pop` | O(1) | 只动尾部 |
| `shift` / `unshift` | **O(n)** | 要整体移动元素 |
| `slice` | O(k) | 复制 k 个元素，不是 O(1) |
| `indexOf` / `includes` / `find` | O(n) | 线性查找 |
| `splice` | O(n) | 中间插入删除要挪元素 |
| `sort` | O(n log n) | — |

结论：**头部增删很贵**。需要频繁从头部操作，用两个栈模拟队列、或者用索引指针 + 反转数组。

## 哈希表（对象 / Map）

平均 O(1) 增删查，最坏 O(n)（哈希冲突严重时退化成链表）。

- `Map` 的 key 可以是任意类型、保持插入顺序；普通对象的 key 只能是字符串或 Symbol。
- 典型题型：两数之和、字符计数、去重、分组。

## 栈、队列、链表

- **栈（LIFO）**：`push` / `pop` / 取栈顶。典型场景：括号匹配、函数调用栈、撤销、单调栈。
- **队列（FIFO）**：`push` / `shift`。但 `shift` 是 O(n)，数据量大时用「两个栈倒腾」或「头尾指针 + 数组」模拟。
- **链表**：插入删除 O(1)（已知前驱节点），查找 O(n)，不能随机访问。典型题：反转链表、快慢指针找环、合并两个有序链表。

## 递归与循环

复杂度一样，递归多一层函数调用开销，深了还会栈溢出。**能用循环就用循环**，递归适合树、分治这类天然递归的结构。

## 二分查找 O(log n)

前提是**数组有序**。核心是维护 `low` / `high` 两个指针，每次砍掉一半。

```js
function binarySearch(arr, target) {
  let low = 0
  let high = arr.length - 1
  while (low <= high) {
    const mid = (low + high) >> 1
    if (arr[mid] === target) return mid
    if (arr[mid] < target) low = mid + 1
    else high = mid - 1
  }
  return -1
}
```

变体：找左边界 / 右边界、旋转有序数组、二分答案。

## 二叉树

**遍历**：前序（根左右）、中序（左根右）、后序（左右根）是 DFS；层序是 BFS，用队列。

**二叉搜索树（BST）**：左子树所有节点 < 根 < 右子树所有节点。所以中序遍历出来是有序数组；查找平均 O(log n)，但插入顺序不好会退化成链表，变成 O(n)。

**堆**：完全二叉树，但用数组存。

- 索引关系：左 `2i+1`、右 `2i+2`、父 `(i-1)>>1`。
- 大顶堆：任意节点都大于它的子节点；小顶堆反过来。
- 建堆 O(n)，插入 / 删除堆顶 O(log n)。
- 典型用途：TopK、优先队列、合并 K 个有序链表。

## 动态规划

三个要素：**状态定义、转移方程、边界条件**。特征是两个：重叠子问题、最优子结构。

实现上自底向上（数组缓存）比递归 + 记忆化更省空间、也更快。

典型题：斐波那契、爬楼梯、最长递增子序列、最大子数组和、背包。

## 贪心

每一步都取局部最优。能用贪心的前提是**局部最优能推出全局最优**，而这一点往往需要证明（比如区间调度按结束时间排序）。

## 排序复杂度速查

| 算法 | 平均 | 最坏 | 额外空间 | 稳定 |
|---|---|---|---|---|
| 冒泡 / 插入 / 选择 | O(n²) | O(n²) | O(1) | 插入稳定 |
| 快排 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 归并 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |

实际开发直接 `sort()`，V8 用的是 TimSort（归并 + 插入，稳定）。

## 前端高频题型

每题只需要说清「用什么结构 + 复杂度」：

- 两数之和 → 哈希表，O(n)
- 有效括号 → 栈，O(n)
- 反转链表 / 环形链表 → 指针、快慢指针，O(n)
- 二叉树层序遍历 → 队列 BFS
- 合并两个有序数组 / 链表 → 双指针，O(m+n)
- 最大子数组和 → 一次遍历维护当前和（Kadane）
- 最长无重复子串 → 滑动窗口 + 哈希
- LRU 缓存 → `Map` 或 哈希 + 双向链表
- 数组扁平化 / 去重 → 递归 / `Set`
- 防抖节流 → 见 `01 JS语言核心`
