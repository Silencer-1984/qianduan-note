# 常见陷阱

## 常见陷阱 10 例

这一节比背题重要。**你的定位是"用 AI 干活"，那核心能力就是"一眼看出 AI 写的代码哪里会炸"。**

### 坑 1：可变默认参数

```python
def add(item, bucket=[]):        # ❌ 默认值只在函数定义时创建一次
    bucket.append(item)
    return bucket

add(1)   # [1]
add(2)   # [1, 2] ← 应该是 [2]
```
**修复**：
```python
def add(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket
```
**面试价值**：这是最经典的 Python 坑，问到概率极高。

### 坑 2：闭包晚绑定

```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])       # [2, 2, 2] ← 不是 [0, 1, 2]
```
**原因**：lambda 里引用的是变量 `i` 本身，循环结束后 `i` 已经是 2。
**修复**：`lambda i=i: i`（把当前值绑成默认参数）。

### 坑 3：`is` 和 `==` 混用

```python
a = 256; b = 256
a is b          # True  ← 小整数有缓存
a = 257; b = 257
a is b          # 可能是 False
```
**规则**：**比数值永远用 `==`；比 `None` 永远用 `is None`。**

### 坑 4：`async def` 里跑同步阻塞代码

```python
async def handler():
    time.sleep(1)                    # ❌ 整个事件循环卡住 1 秒
    requests.get("https://...")      # ❌ 同样阻塞
```
**修复**：`await asyncio.sleep(1)`；IO 用 `httpx.AsyncClient`；实在要用同步库就 `run_in_executor` 丢线程池。
**这条对你最重要**——FastAPI 的性能全靠这个。

### 坑 5：浅拷贝当深拷贝用

见 2.2。**信号**：看到 `.copy()` 就确认一下里面有没有嵌套的可变对象。

### 坑 6：异常被吞掉

```python
try:
    do_something()
except:
    pass                    # ❌ 出错了你永远不知道
```
**修复**：`except Exception as e: logger.exception(e)`，或者至少 `raise` 抛出去。

### 坑 7：用推导式做副作用

```python
[print(x) for x in data]     # 能跑，但会生成一个无用的列表
```
**修复**：普通 `for` 循环。推导式是用来**构造集合**的，不是用来执行动作的。

### 坑 8：`get` 和 `setdefault` 搞混

```python
d.get("k", [])              # 只返回默认值，不会写进字典
d.setdefault("k", [])       # 会把默认值写进去
```
**坑**：用 `get` 拿到列表后 append，结果**下次取还是空**——因为根本没存进字典。

### 坑 9：浮点数和整数除法

```python
0.1 + 0.2 == 0.3            # False
-7 // 2                     # -4（向下取整，不是 -3）
```
**规则**：金额用 `Decimal` 或整数分；负数除法要确认取整方向。

### 坑 10：照着过时 API 写

| 过时写法 | 现在的写法 |
|---|---|
| `pandas.fillna(method='bfill')` | `df.bfill()` |
| LangChain `create_openai_functions_agent` | `create_tool_calling_agent` 或 LangGraph |
| `datetime.utcnow()` | `datetime.now(timezone.utc)` |

**这不是你的错，是训练数据的问题。** 养成习惯：**AI 给的代码，先确认库版本**。

## 错误示范

这部分不是挑刺，是**练习"读代码找问题"**。原题里这几处的实现值得商榷：

### 7.1 原题 25：算 n! 的末尾零
```python
fact = n
while n > 1:
    fact *= n - 1
    n -= 1
```
**问题**：先把 n! 算出来，n 稍大就是个天文数字，**慢且占内存**。
**正解**：末尾零的个数 = 因子中 5 的个数：
```python
def trailing_zeros(n):
    count = 0
    while n >= 5:
        n //= 5
        count += n
    return count
```
**面试价值**：如果被问到，能说出"朴素做法是算阶乘，但会溢出/变慢，数学上等价于数 5 的因子"——**这一句就能体现思维层次**。

### 7.2 原题 28：找缺失的数字
```python
actual_sum = (n * (n + 1)) / 2      # ❌ 结果是 float
```
**问题**：n 很大时浮点数精度丢失，结果可能差 1。
**修复**：用 `// 2`，或者用 `(n * (n + 1)) >> 1`。

### 7.3 原题 31：毕达哥拉斯三元组
```python
for i in range(n):
    array[i] = array[i] ** 2        # ❌ 原地修改了入参
```
**问题**：这个函数会**改掉调用方的数组**，属于隐式副作用。
**修复**：`squares = sorted(x ** 2 for x in array)`。

### 7.4 原题 20、41：过时 API
`fillna(method=...)` 在 pandas 2.x 已废弃；LangChain 的 Agent 创建接口在新版已换。**这也是为什么"能跑"不等于"能上生产"**。
